# Public roadmap

## 0.1 — Reference prototype

- Publish the sanitized Expo interaction prototype
- Document simulated data and hardware boundaries
- Establish issue, pull-request, security, and CI workflows

## 0.2 — Testable device contracts

- Extract typed camera-recognition and load-cell adapter interfaces
- Add deterministic fixtures for recognition, stabilization, tare, and disconnect states
- Add tests for nutrition calculations and state transitions
- Document a mock firmware event protocol

## 0.3 — Cross-screen motion specification

- Describe mobile-to-embedded state mapping
- Add reduced-motion behavior and timing tokens
- Publish implementation-neutral animation state charts

## Later exploration

- English localization
- Optional sample BLE transport using non-proprietary fixtures
- Community-provided food-data adapters with source attribution
- Maintainer automation for issue triage, review checklists, and release notes

Roadmap items are proposals, not promises. Scope will evolve through public issues and maintainer review.
