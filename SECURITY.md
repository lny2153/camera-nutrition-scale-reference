# Security policy

This repository is an early research prototype and does not yet connect to production hardware, accounts, or cloud services.

Please report a suspected vulnerability privately through GitHub's security advisory feature instead of opening a public issue. Include the affected revision, reproduction steps, impact, and any suggested mitigation. Do not test against systems or devices you do not own or have permission to assess.

Never include API keys, device credentials, personal nutrition records, or confidential product information in a report.

Dependency advisories are tracked through Dependabot. Some Expo SDK 54 transitive advisories currently require a breaking SDK upgrade; they will be handled as an explicit compatibility milestone rather than with an unsafe forced update.
