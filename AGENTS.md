# Repository guidance

- This is an Expo SDK 54, React Native, TypeScript, and Expo Router project.
- Preserve Web, iOS, and Android compatibility.
- Keep hardware and recognition behavior simulated unless an issue explicitly adds a public adapter.
- Never add company-confidential assets, credentials, private datasets, real user records, or unlicensed media.
- Make small, reviewable changes and reuse existing components and theme tokens.
- Run `npm run typecheck` and `npm run lint` before reporting completion.
- Treat nutrition values as illustrative unless a public source and validation process are documented.
